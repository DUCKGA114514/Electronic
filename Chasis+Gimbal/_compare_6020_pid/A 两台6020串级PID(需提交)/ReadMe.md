# 本工程基于一台6020的串级PID,教程参考了中科大电控教程

## 主要实现目标，电机在0度突变到90度再回0度循环（参数可以自行更改），目标角度1s变化一次，开了三个定时器（反正不用也没用ovo）

## 第一个定时器是1hz（时间间隔其实有点短，导致波不是很好看,但也可能是我调参的问题），作用是更改目标角度；第二个是100hz，用于角度环的计算；第三个是1000hz，用于速度环的计算

## 至于角度环和速度环为什么要以不同频率计算，我认为，角度是一个慢的过程，而速度是一个快的过程，就像是老师下达了一个目标，可以当作角度环，你是速度环，你去执行，执行是需要花费一点时间的是吧？所以如果角度环和速度环同频，可能会出现冲突，具体可为动态不同 + 控制带宽不同 + 稳定性与抗噪需求不同

## 也可以这样想，本人正在考驾照

把系统想成开车：

- **速度环**：踩油门、刹车（每时每刻都在调）
- **角度环**：看导航决定往哪开（不用每毫秒改一次）

如果导航和油门同时“抢方向盘”，车一定不稳。
