# 工程说明



## 工程中有些数字加上U是为了和要用的数据分开来，加U的一般是常量和标志位判断，不加U的一般是会改变的数据，例如接收数据



1. **工程结构与分层**

   - `Module/DT7`：DT7/DR16 遥控解析模块，负责 UART5 + DMA + Idle 解包。
   - `Module/GM3508`： 3508 电机反馈解析与 CAN2 电流发送。
   - `Moudule/GM6020`:  6020电机反馈解析与CAN1电压发送（根据实际情况改成电流）
   - `Moudule/AHRS`:   大疆官方给的四元数姿态解算例程
   - `Moudule/USB_Vision` :    USB 视觉协议解析模块：维护视觉目标、在线状态以及给上位机回传的遥测缓存
   - `APP/Vision`  :   与视觉联合任务，负责接收解算视觉数据，发送打包欧拉角给视觉
   - `APP/RC`：仅负责上层输入设备初始化与 1ms 在线维护。
   - `APP/Chasis`：底盘主控制层，负责模式机、运动指令、逆解、闭环和安全保护。
   - `APP/Gimbal`:  云台主控制层，负责云台模式，计算角度，以及发送电压指令给GM6020
   - `APP/INS` / `APP/Vision`：BMI088 姿态解算->使用大疆官方AHRS文件与 USB 视觉联动任务。

2. **实时性与任务设计**
   - `Chassis_Task` 使用 `osDelayUntil()` 运行在 **1kHz**。
   - Gimbal_Task 使用 `osDelayUntil()` 运行在 **1kHz**。
   - `RC_Task` 以 1ms 周期维护遥控在线状态。
   - USB 接收中断并进入USB_RX队列，之后在Vision解算任务中进行解算
   - CAN 接收使用中断入队，底盘任务统一出队处理，避免中断中做重计算。

3. **新增/实现的赛场功能**(参考了robowalker战队，文华战队，华南虎战队步兵开源例程)

   - DT7 三段开关控制模式：安全停机 / 常规遥控 / 小陀螺。
   - DT7 三段开关控制速度挡位：低速 / 中速 / 高速。
   - 软启动与软切向，减小打滑与电流尖峰。
   - 回中柔性刹车，提升站停稳定性。
   - 电机离线保护、遥控失联保护、极限倾覆保护接口预留。
   - 总电流限幅，降低急变向与撞击恢复时的总线冲击。

4. **HAL 与底层外设**
   - 使用 HAL 的 `HAL_UARTEx_ReceiveToIdle_DMA()` 实现遥控接收。
   - 使用 HAL CAN 过滤器、启动与 FIFO0 接收中断。
   - 增加 `CAN_Send_Handle()`，支持 CAN1/CAN2 分总线发送。

5. **可维护性改进**

   - 关键参数统一放在头文件中，便于整定。
   - 但是各文件的解耦性设计的不算很好
   - 没有统一的数据流结构
   - 难以复用，换设备几乎要重写代码

6. **当前默认约定**
   - CAN1 给云台，CAN2 用于底盘 3508。
   - UART5用于遥控器数据接收
   - UART6,UART1暂时预留给裁判系统还有上位机波形显示
   - 轮序：前左、前右、后左、后右。
   - `S1`：上=安全停机，中=常规遥控，下=小陀螺。
   - `S2`：上=低速，中=中速，下=高速。
   - 右手纵杆 `ch1` 前后，右手横杆 `ch0` 平移，左手横杆 `ch2` 自旋。
